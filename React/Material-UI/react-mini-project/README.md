# Weather App (Practice Project)

This is a simple weather application built as a practice project. It allows users to search for weather information for different cities.

## Features

- Search for weather by city name.
- Displays temperature, humidity, and weather description.

## API Used

This application utilizes the [OpenWeather API](https://openweathermap.org/) to fetch weather data.
