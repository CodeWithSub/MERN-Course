# WhatsApp Clone (Basic Chat App)

A simple **CRUD chat application** built with **Node.js, Express, MongoDB (Mongoose), and EJS**.  
It allows users to create, read, update, and delete chat messages.

---

## 🚀 Features
- View all chats
- Create a new chat
- Edit a chat message
- Delete a chat message
- MongoDB integration with Mongoose

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express
- **Database:** MongoDB with Mongoose
- **Templating Engine:** EJS
- **Other:** Method-Override, Static files with Express
