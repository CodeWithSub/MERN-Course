# Simple Express.js Posts CRUD App

A basic CRUD (Create, Read, Update, Delete) application built with **Express.js** and **EJS** for rendering views.  
This project demonstrates how to build a simple blogging/posting system with in-memory storage.

---

## Features
- View all posts
- Create a new post
- View details of a single post
- Edit an existing post
- Delete a post

---

## Tech Stack
- [Node.js](https://nodejs.org/)
- [Express.js](https://expressjs.com/)
- [EJS](https://ejs.co/)
- [UUID](https://www.npmjs.com/package/uuid) (for unique post IDs)
- [Method-Override](https://www.npmjs.com/package/method-override) (for PATCH/DELETE requests in forms)
