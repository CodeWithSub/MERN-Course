# JavaScript Basics – MERN Course

This folder contains standalone JavaScript (`.js`) files that cover fundamental topics such as variables, data types, functions, and more.

## 🛠 How to Run These Files

To keep things clean and simple, these files are not embedded in HTML using `<script>` tags. Instead, they are plain `.js` files that you can run directly in your terminal using **Node.js**.

> ⚠️ **Note:** You do **not** need to learn Node.js right now. It’s only used here to run the files easily in your terminal.

---

## ✅ Running JavaScript in VS Code (for Beginners)

If you're new to JavaScript and wondering how to see the output of these files:

1. **Install Node.js**  
   Download it from [https://nodejs.org](https://nodejs.org) and install it on your machine.

2. **Open the folder in VS Code**

3. **Run a file**  
   Open a terminal in VS Code and run a file like this:
   ```bash
   node 01.basics.js
