# 📝 To-Do List CLI (JavaScript)

A simple browser-based to-do list app using JavaScript prompts.

## ✅ Features

- Add tasks  
- List all tasks  
- Delete tasks by index  
- Quit the app

## 🚀 How to Run

1. Copy the code into a `<script>` tag in an HTML file.
2. Open it in your browser.
3. Use the prompts to manage your tasks.

## 🧾 Commands

- `add` – Add a new task  
- `list` – Show all tasks  
- `delete` – Delete a task by its index  
- `quit` – Exit the app

## 🛠️ Notes

- The app runs in the browser using prompt() and console.log(); it   won't work in Node.js.

- Deletion is done by index, so be sure to use list before deleting.

- There's a small typo in the add prompt: tou should be you. You can fix that if you like.
